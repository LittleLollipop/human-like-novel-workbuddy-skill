# AI 味用词句式负例清单（修复/创作时规避）

> **定位**：从 error-cases 库拆分的「用词/句式」快速负例清单（模型读，非机器规则——机器层见 `error-cases/_rules.json`）。
> **用途**：①创作新句子时规避；②**修复/改稿动作必用**（修复前过一遍、修复后扫改过的位置）——修复时模型上下文只有「原文+指出的句子」，无负例约束时，新写的句子会退回训练语料里最高频的 AI 味表达（用户 2026-08-16 观察：每次修复细节时新句特别容易出 AI 味）。
> **来源标注**：`#编号`=error-cases 案例；「项目新踩」=各书修正记录提炼，未入 error-cases。
> **积累规则**：踩到新坑往对应分类追加（错误→正确），并记项目日志；本清单与 error-cases 同步演进。

## 一、词级黑名单（直接禁/慎用）

### 1. 身体反应陈词滥调（#074）
`指节发白 / 指节泛白 / 喉头发紧 / 喉咙发紧 / 下颌线绷紧 / 下颌绷紧 / 瞳孔骤缩 / 瞳孔一缩 / 后背发凉 / 脊背发凉 / 心头一凛 / 倒吸一口凉气`
→ 换**具体、可感知、与上下文绑定的动作或物件状态**（攥着某物/物件嵌进掌纹/某处发烫发颤）。

### 2. 静默瞬间类（项目新踩 某章）
`一瞬 / 静了一瞬 / 安静了一瞬 / 静默了片刻 / 半晌无声`
→ 改具体：**没人接话 / 起哄声停了 / 几十道目光钉在他身上**（用可感动作替代抽象时间切片）。

### 3. 情绪动作套路（自查高频清单）
`若有所思 / 微微一笑 / 心头一凛 / 不禁 / 仿佛 / 缓缓 / 轻轻 / 嘴角扬起 / 眼底闪过 / 一点一点 / 几不可察 / 见过太多`
→ 删或改具体动作；「轻轻/缓缓」尤其高频复发，能换即换。

### 4. 突发/程度前缀（#023/#023b，机器已查）
`一X 四字模板（一颤/一顿/一沉/一缩…）`、`猛地一 / 忽地一 / 蓦地一 / 齐齐一 / 心头一 / 瞳孔一 / 指尖一 / 脚步一 / 脚下一 / 一字一顿`
→ 廉价叙述节拍，换具体动词与情境。

### 5. 程度量词（#020，机器已查）
`X了一分` → 套路化突变量词，禁。

### 6. 无场景支撑的时间对照（项目新踩 某章）
`走得比来时急 / 比刚才更…`（副词性时间对照必须有场景动作支撑；场景里没有「来/去」动作时，对照不成立）→ 只留本体的「走得急，又有点发飘」。

### 7. 语义矛盾组合（项目新踩 某章）
`翻来覆去 + 一遍`（多次×一次）→ 「翻来覆去地捋」（去「一遍」）；同类：反复×一次、再三×一下。

## 二、句式级模式（错误 → 正确）

### 1. 比喻式总结金句（项目新踩 某章）
`「X 身后，站着 Y」「眼睛长在 Z 里」`（前句已传达的比喻式收尾=AI 味重灾区）→ **直接删**或改具体观察；写前先问「前句说完了吗」。

### 2. 抽象名词组合心理描写（项目新踩 某章）
`「心虚的慌张」「带着一丝发紧」`（抽象名词叠抽象名词，读者无画面）→ 改具体动作/声音（「嗓子绷得紧紧的」「走得急，又有点发飘」）。

### 3. 否定链对比（#086）
`「不是 X，也不是 Y，而是 Z」`三截否定链 → `「比 X…，与 Y 也非一路，独成…」`或 `「X 是…，Y 是…，此处是…」`。

### 4. 解释性尾巴（#039，机器已查）
`「——X 的那种 Y」`把判断重描一遍 → 删。

### 5. 纯装饰俗套比喻（#041）
喻体反应与所修饰动作矛盾、或不承载情节信息的比喻 → 删；比喻必须「写动作体感」或「推情节」。

### 6. 假伏笔比喻（#043）
`「像是活物」`但后续不会兑现的暗示 → 删（不埋不兑现的钩子）。

### 7. 疯狂点题/强行串线（#046）
作者借角色反应把小事往大阴谋/主题上绑（无证据、无必要）→ 事件自己说话，读者自己联想。

### 8. 作者跳出点题/章首章尾抒情感慨（#073）
章末排比宣言（「唱给评委听，唱给满城听」「坐定了」式升华）→ **动作收束**（具体决定/动作/意象，不点题）。

### 9. show 后 tell（#068）
动作体感已传达再补总结句 → 停手；「动作已到，结论读者自取」。

### 10. 套路化句构（#020/#023）
`「X了一分」「Noun 一 Verb」` → 换具体写法。

### 11. 同义堆叠啰嗦（#059）
让步理由不对/重复铺陈来头 → 一句说清，删重复。

### 12. 假转折（#058）
`「可/但」`硬连无因果的两事 → 删转折词或补因果。

### 13. 无信息量总结/过度修辞（#064）
长段修饰后无信息增量 → 删；「这句读者已经知道了吗」=硬标准。

### 14. 内心总结重复前文（项目新踩 某章）
拼线索/复盘时把前文已说的事实再说一遍（「补过的卷宗，干净得不像话」式复述）→ 删，只留新推断。

### 15. 收尾对白原样复用（项目新踩 某章）
同一收尾对白（「你等着/我等着，好走」）跨场景原样出现两次 → 第二次必须升级（换更惨/更欠打/更具体的写法），禁复制粘贴。

### 16. 「又补了一句」接内心（项目新踩 某章）
`「心里得意，又补了一句：局先落在这儿…」`（「补一句」是接说话的词，后面却是内心）→ 「把笛子转了个圈，心里盘算着：…」。

### 17. 叙述回顾段大跨度时间词（#111）
`「当年/从前/那时/多年前」`误用于数天前有明确锚点的事件 → 「那天/上回/前些天」；判断法：读者能数出几天前，就不能用「当年」。

### 18. 角色自夸与设定自洽（项目新踩 某章）
夸角色能力时不得否定其已有本职（主角是行会基层跑腿的，写「不去行会当差可惜了」=自贬本职）→ 落回「老本行」「天生吃这碗饭」式自洽自夸。

## 三、修复/改稿动作使用法（必做）

1. **修复前**：过一遍本清单（重点：词级①②③ + 句式级与本次问题同类的条目），新写的句子规避。
2. **修复后**：只扫**改过的位置**（非整章）——词级黑名单逐词过 + 句式级模式逐条对照；再跑机检（项目 `.check_chapter.py` + 技能 `check_error_cases.py`）。
3. **改词联动**：改动一个词后检查相邻对话的呼应词（例：A 句改「规矩」，B 句就不能还接「正经」）。
4. **踩到新坑**：往对应分类追加（错误→正确），同步记项目日志；机器可判定的词级可补进 `error-cases/_rules.json`。
